# web/ (owners: **WS3** and **WS4**)

Next.js (App Router) + TypeScript strict + Tailwind + shadcn/ui, pnpm.

| Path | Owner |
| --- | --- |
| `app/` (except `app/editor/`), `components/ui/`, `components/adapters/`, `components/search/`, `lib/api/` | WS3 |
| `app/editor/`, `components/editor/`, `lib/audio/`, `stores/` | WS4 |
| `lib/types/` | generated by `make schema` (contract, never hand-edit) |

```bash
pnpm install
pnpm dev          # http://localhost:3000  (make dev-web)
pnpm test         # vitest
pnpm lint && pnpm typecheck
```

`lib/api/client.ts` is the only code that knows URLs. With `NEXT_PUBLIC_USE_FIXTURES=1` it answers from
`../shared/fixtures` (no backend), else it calls `NEXT_PUBLIC_API_URL`. `next.config.ts` reads the `NEXT_PUBLIC_*`
keys from the repo-root `.env`.
